Taxas das formas de pagamento

Defina a taxa percentual de cada forma de pagamento. O financeiro aplica automaticamente, sem preencher taxa manual em cada mensalidade.

Exemplo: se o crédito tiver taxa de 2,34%, digite 2.34. Mensalidades já pagas preservam a taxa gravada no momento do recebimento.

Importar dados de crianças

Importe cadastros por link publicado em CSV ou arquivo CSV exportado do Google Sheets.
Colunas aceitas: Nome da criança, Status, Data de nascimento, Responsável, CPF do responsável, Telefone, Emergência, Endereço, Atividades, Horas contratadas, Mensalidade, Dia de vencimento e Observações.
Para várias atividades, separe por ponto e vírgula. Exemplo: Ballet; Karatê; Reforço.

Exportar dados de crianças

Exporte apenas os dados das crianças cadastradas, sem financeiro, despesas ou chamada.
Não são criados backups locais de dados pessoais. A exportação CSV é uma ação manual de relatório.

Categorias de despesas

Cadastre categorias para organizar as contas e selecionar na subaba Despesas.

Cadastro de atividades

Cadastre as atividades oferecidas e o valor padrão. Depois, escolha e edite os valores individualmente no cadastro de cada criança.

Backup no servidor

O ERP não grava arquivos de backup neste dispositivo. Os snapshots de proteção são mantidos no servidor.

Proteção dos dados Backup local desativado Nenhum backup com dados pessoais é criado no localStorage, sessionStorage ou Downloads.

Controle de acesso

Escolha se o sistema deve pedir senha ao abrir.

Quando estiver desativado, o app abre direto. Quando estiver habilitado, use a senha cadastrada ou a senha padrão 2704.

Alterar senha local

Use esta área apenas se quiser definir uma senha personalizada para quando a proteção estiver habilitada.
